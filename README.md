# 🚄 Subway Surfers Edu 3D — Edisi Produktif SMK Budi Agung

Game edukasi **3D Endless Runner** bergaya *Subway Surfers* yang dipadukan dengan **Tiang Pit Stop Kuis** mata pelajaran Produktif SMK (**Informatika, Pemrograman Web/RPL, Teknik Komputer & Jaringan/TKJ, serta Sistem Operasi & Hardware**).

## 🎮 Fitur Utama
- **Tiang Pit Stop Kuis & Radar Jarak**: Gerbang Pit Stop 3D terlihat dari kejauhan lengkap dengan radar jarak (`75m` → `0m`) dan pengereman halus (*slow-motion braking*) agar pemain bersiap sebelum menjawab soal.
- **Kuis Penyelamat (*Revive Quiz*)**: Kesempatan kedua saat menabrak rintangan dengan menjawab soal kuis beserta pembahasan materi.
- **Grafis 3D HD Organik**: Karakter 3D bersendi lengkap, kereta cepat aerodinamis (*MRT Bullet Train*), awan 3D, gedung kota, dan audio synthesizer Web Audio API (100% tanpa aset eksternal yang rawan gagal muat).
- **64+ Soal Produktif SMK + Panel Bank Soal Guru**: Guru dapat menambah/mengedit soal, menambah mata pelajaran baru, serta mengimpor/mengekspor bank soal (`.json`) dan nilai siswa (`.csv`).

## 🚀 Cara Memainkan
1. **Secara Online (GitHub Pages)**: Buka URL GitHub Pages repository ini di browser HP, Tablet, atau PC.
2. **Secara Offline**: Klik 2x file `index.html` atau `JALANKAN_GAME.bat`.
